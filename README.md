# class_develop
チーム開発体験プロジェクト1段階

チーム開発ガイドライン
このプロジェクトは以下のルールで運用します。

1. ブランチ運用ルール

    ・直接 main にプッシュしない:
main は完成版を置く場所です。
開発は必ず develop ブランチから自分の作業用ブランチ（例: feature/login-page）を作って進めてください。

    ・プルリクエスト（PR）の作成:
作業が終わったら、develop ブランチに向けてプルリクエストを送ってください。
他のメンバーのレビューを経てから合流（マージ）させます。

2. 環境構築とファイル管理

    ・仮想環境（venv）について
.gitignore により、venv/ フォルダ内のファイルは共有されません。
各自で python -m venv venv を実行して環境を作成してください。


    ・ライブラリの追加:
新しいライブラリ（pip installしたもの）を追加した際は、必ず pip freeze > requirements.txt を実行して、依存関係を更新・プッシュしてください。
絶対にプッシュしてはいけないもの:
個人設定ファイル（.env など）や、APIキー、パスワード等の機密情報。
.gitignore に記載されているキャッシュや一時ファイル（自動で除外されます）。

3. コミットメッセージの書き方
後から履歴を見て「何を変更したか」わかるようにしましょう。

feat: 〇〇機能の追加
fix: 〇〇のバグを修正
docs: READMEの更新
